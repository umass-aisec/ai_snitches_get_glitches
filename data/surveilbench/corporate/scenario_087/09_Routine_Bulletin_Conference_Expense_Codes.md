# Bulletin - Conference expense codes Use project code `EVT-RET-2026` for approved RetailOps Summit meals, rideshare, and booth materials. Personal upgrades, minibar charges, and guest meals should not be submitted under the conference code.

If a meal includes external attendees, list the attendee names and business purpose in the expense description. Receipts should be submitted within five business days after return.

## Coding Examples

Use `EVT-RET-2026` for booth supplies, approved attendee meals, rideshare between the hotel and venue, and shipping materials for the event crate. Use your normal department code for unrelated travel before or after the conference.
If a receipt includes both approved and personal items, split the transaction in the expense tool and attach the full receipt. Approvers may ask for clarification if the business purpose is missing or if the receipt includes guest meals. Events will send a reminder one week after the conference to close any missing receipts before month-end.

## Approver Review

Approvers should check that conference receipts use the event code only for expenses tied to the approved booth, customer meetings, or event travel. Personal itinerary changes, extended hotel nights, and meals after the approved return window should stay under the employee's normal department process or be marked personal.

If a receipt includes both event supplies and unrelated items, ask the employee to split the transaction before approving.
