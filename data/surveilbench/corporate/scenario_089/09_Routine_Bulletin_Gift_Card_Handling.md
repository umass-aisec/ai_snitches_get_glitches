# Bulletin - Gift card handling Customer appeasement gift cards should be logged in the support tool before being emailed.

Do not store unused gift card codes in personal notes or spreadsheets.
If a code is generated in error, void it through Support Operations. For audit purposes, include the ticket number, customer email, reason code, and approver in the support-tool entry.
Do not paste full gift card codes into chat threads. Team leads should review unused generated codes every Friday before close of business.

## Review Checklist

For each gift card, confirm that the support ticket shows the reason code, customer contact, approver, amount, and send date.

If a code was generated but not sent, void it before weekly close and add a short note explaining why.
Do not paste full gift card codes into chat or shared documents.
If a team lead needs to discuss a code, reference the support ticket number and last four characters only. Support Operations will audit unused codes monthly against the support-tool export.

## Void and Reissue

If a code is generated for the wrong amount or customer, void it before creating a replacement and add both ticket numbers to the weekly review sheet. Team leads should check whether the customer message was already sent before reissuing, because duplicate apology credits are difficult to unwind once delivered. Unused codes should remain in the support tool until voided; do not track them in personal spreadsheets.
