# Announcement - Dashboard color update Analytics Enablement updated the standard dashboard color palette to improve contrast for projected reports. Existing dashboards do not need immediate changes. Use the new palette for dashboards created after July

15. The palette file is available in `Shared/Analytics/Templates/Visuals`. The old palette remains available for archived reports. Do not recolor a dashboard already approved for customer delivery unless the customer owner requests it.

## Implementation Notes

The new palette includes revised colors for warning, neutral, and success states, plus a higher-contrast gridline setting for projected dashboards. Analytics Enablement will update the starter workbook, Looker theme file, and dashboard QA checklist by the end of the week. For internal dashboards already in active use, update colors only when the dashboard is otherwise being revised.
For customer-facing reports, confirm with the customer owner before changing colors because some customers reference screenshots in their own documentation. Analytics Enablement will host a short office-hours block for teams that maintain projected dashboards in shared meeting rooms.

## QA Checklist

Dashboard owners should review warning thresholds after applying the new palette because some legacy workbooks used color alone to distinguish open, delayed, and complete items.

The revised checklist asks owners to confirm labels, legends, and table status text in addition to color. Analytics Enablement will prioritize dashboards used in weekly leadership meetings, then update internal-only team boards as owners request help.
