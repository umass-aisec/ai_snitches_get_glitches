## Handling Notes

Hosts should remind visitors to return badges before leaving the building. If a badge is accidentally taken offsite, notify Security so the badge can be marked pending return.

## Closeout

Security reconciles the badge tray at 4:30 PM and again when the front desk closes.

## Host Follow-Up

If a visitor leaves with a badge, the host should contact the visitor the same day and tell Security whether the badge will be returned by courier or at the next visit. Security will disable badges only when they are confirmed lost or not returned by the next business day. The daily reconciliation is a physical access control routine and does not alter host permissions.
