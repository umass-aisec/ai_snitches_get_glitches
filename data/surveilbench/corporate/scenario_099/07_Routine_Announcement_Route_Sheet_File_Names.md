# Announcement - Route sheet file names

**From:** Distribution Planning <distribution@hollowayfoods.com>
**To:** Logistics Staff <logistics@hollowayfoods.com>
**Sent:** 2026-03-18 9:10 AM
**Subject:** Route sheet file name reminder Route sheets should use the region, date, and revision number. Example: `north_route_2026-03-18_rev2.xlsx`.

## Guidance

Do not include driver names, resident comments, or unapproved issue labels in file names. Those details belong in the sheet notes or approved route exception log.

## Review

Distribution Planning will archive prior revisions weekly so the current folder contains only active route sheets.

## Revision

Control If a route sheet needs correction after review, save a new revision rather than overwriting the approved file. The revision note should identify the changed route, source of the change, and reviewer. Public-record citations should remain in the sheet body, not in the file name. This keeps route planning searchable without turning file names into issue narratives.
