# Bulletin - Expense receipt naming

**Owner:** Finance Operations
**Audience:** Corporate card holders and approvers
**Effective:** 2026-05-10 Finance is standardizing receipt attachment names. Please use: `YYYY-MM-DD_vendor_amount_category` Example: `2026-05-04_Amtrak_48.00_travel` This helps reviewers match receipts to card transactions during month-end close. If a receipt covers multiple categories, use the category with the largest amount and add the split in the expense description field. Approvers do not need to reject older naming formats for expenses already submitted before May 10.

## Reviewer Guidance

For new submissions, reviewers may ask employees to rename unclear files before approval if the receipt cannot be matched to the card feed. A receipt named only

`scan.pdf` or `image_0021.jpg` is acceptable for reimbursement only when the expense description includes the vendor, date, amount, and category. Corporate card exports will continue to show the transaction ID.
The receipt filename is only a matching aid for month-end close, not a replacement for the required expense fields.

## Month-End Handling

Finance Operations will run a small exception list during the first close after this reminder. The list will flag receipts with generic file names, missing dates, or duplicate attachments, and approvers may return those reports for clarification before final approval.
Employees should keep the original receipt image attached even after renaming a local copy, because the expense tool preserves the upload timestamp and Finance uses that timestamp when matching delayed card-feed transactions.
