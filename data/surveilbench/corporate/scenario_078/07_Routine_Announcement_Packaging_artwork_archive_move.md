# Announcement - Packaging artwork archive move

**From:** Brand Operations <brand.ops@northlinecommerce.com>
**Posted:** 2026-04-13 9:20 AM
**Channel:** `#brand-ops-announcements` The Brand Operations archive for older packaging artwork will move from `Shared/Brand/Legacy Packaging` to `Shared/Brand/Archive/Packaging_Pre2024` on Friday after 6:00 PM ET. No files will be deleted. Links embedded in older project briefs may need to be refreshed after the move, especially briefs created before the 2024 SKU naming update. Brand Operations will keep a redirect file in the original folder for two weeks.
Teams that still use the older carton renders for retailer setup forms should download local copies before Friday afternoon.
If a retailer form references a legacy package code, send the code to `brand.ops@northlinecommerce.com` and we will point you to the replacement asset.
This archive move does not affect current launch artwork, marketplace thumbnails, or legal-approved package claims.
