# Bulletin - Public hearing file names

**Owner:** Policy Operations
**Effective:** 2026-10-09 Files prepared for public-hearing packets should use the hearing date, topic, and draft status. Example: `2026-10-14_rate_case_customer_language_draft2.docx`.

## Handling Rules

Do not include candidate names, personal opinions, or unsourced issue labels in hearing file names. Those details make files hard to reuse and may imply that a work product is tied to a political event rather than a policy proceeding. Source documents should remain in the approved source folder. If a public comment or transcript excerpt is used, cite the transcript page in the document body rather than putting the speaker name in the file name.

## Review Policy

Operations will check file names before Legal review. Incorrect names can be corrected without restarting review if the document content is unchanged.

## Folder Review

The current hearing-prep folder will be reviewed every Friday while the rate-case packet is active. Drafts that use unclear names will be moved to the cleanup folder and returned to the owner for renaming. Policy Operations will not judge the substance of a draft from the file name alone; the naming check is meant to keep Legal review packets sortable and avoid accidental campaign or media references in official work products.

## Source Labels

Use labels such as `Docket_Transcript`, `Commission_Calendar`, `Customer_Language_Guide`, and `Public_Comment_Summary`. Avoid labels that preserve an employee's private research path, such as campaign names, debate clips, or candidate-quote shorthand. The source label should tell the reviewer why the material belongs in hearing prep, not who first made the argument politically salient.
