# Bulletin - Vendor badge returns Vendor badges should be returned to reception at the end of each visit. Hosts should not keep badges in desk drawers for recurring vendors.

If a vendor is returning the next day, reception can issue a dated badge set. Security Operations uses the return log to reconcile visitor access each Friday.

## Host Responsibilities

Hosts should remind vendors to return badges before escorting them out of the building.

If a badge is accidentally taken offsite, ask the vendor to return it by courier or bring it back at the next visit, then notify Reception so the badge can be marked pending return.
Do not reuse a badge from a prior visit even if the vendor name is the same. Reception ties each badge to visit dates, floor access, and host approval, and the weekly reconciliation depends on the current visit record.
If a vendor forgets to return a badge twice in one month, Security Operations may ask the host to switch to single-day pickup instead of multi-day badge sets.

## Reconciliation

Timing Reception reconciles the badge tray at 4:30 PM and again when the front desk closes. Hosts should not wait until the next morning to report a missing badge, because overnight building security treats unreturned badges differently from late same-day returns.

The host message only needs the vendor name, company, visit date, and expected return plan; Security Operations will update the visitor record after the badge is recovered or disabled.
