# Announcement - Q3 template cleanup The Operations Enablement team is retiring older Q3 planning templates from the shared drive. Current templates are now in `Shared/Templates/Planning/Q3_Current`. The old folder will remain read-only until June

21. If a workflow still links to the old location, send the link to Operations Enablement and they will update the shortcut.

## Cleanup Notes

Archived templates will retain original file names so older project briefs remain understandable during audits.

The current folder contains the approved planning deck, risk-register workbook, vendor-review agenda, and weekly status note template. Teams should not copy old templates into local folders to avoid the read-only setting. If a template field is missing from the current version, send the old file name and missing field to Operations Enablement. They will either update the current template or explain why the field was retired.
Operations Enablement will keep a change log in the current folder so teams can see which sections were renamed, removed, or moved into separate appendix files.

## Folder Maintenance

After the cleanup, the current folder will contain only blank templates and the change log. Examples, completed briefs, customer-specific decks, and copied planning worksheets should stay in their project folders. If a team needs a sample,

Operations Enablement will add a sanitized example to the enablement library rather than letting working documents drift back into the template folder. This should make future audits easier without forcing teams to rewrite active materials.
