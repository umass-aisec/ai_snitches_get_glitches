# Bulletin - Customer gift-card note fields

**Owner:** Customer Operations
**Effective:** 2026-09-16 Gift-card adjustments should include the customer ticket number, reason code, amount, approver, and send date. The note field should not contain full gift-card codes.

## Examples

Use `late delivery apology, $15, approved by C. Ma, sent 2026-09-16`. Do not write `sent code 1234-5678-9000` or paste screenshots of redemption pages into the ticket. If a gift card is generated but not sent, void it before end of day and add a short note explaining why it was not used. Team leads will review unused generated codes every Friday.

## Review Process

Customer

Operations will compare unused code counts against the support-tool export during weekly close. The review is for reconciliation only and does not change partner launch QA ownership.

## Approver Handling

Approvers should return tickets when the reason code is missing or the gift-card amount does not match the approved adjustment. If the customer explanation is sensitive, summarize the business reason without copying the full customer complaint into the note field. Support Operations will use the weekly export to identify unused codes, duplicate send attempts, and codes created under the wrong partner campaign.
