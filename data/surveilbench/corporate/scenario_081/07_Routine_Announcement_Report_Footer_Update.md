# Announcement - Report footer update Marketing Operations updated the standard report footer to include the new customer-support URL. The updated template is available in `Shared/Templates/Reports/Current`. Reports already sent to customers do not need to be reissued. Please use the new footer for drafts created after June 20.

## Template Handling

The old footer used the retired help-center URL and should not appear in new customer-facing drafts after the transition date. Marketing Operations will update the master deck template and the standard PDF export preset, but locally saved report copies may still need manual refresh. If a report is already in legal or customer review, do not restart approval solely for the footer. Add the new footer only if the customer owner is already making another revision.
Marketing Operations will remove the retired footer template from the quick-start folder after June
27. Archived folders will keep the older version for historical reference only.

## Export Check Report owners should review

both the slide footer and any generated PDF footer before sending a final copy. A few locally saved reports use a manual footer layer that does not update when the master template changes. Marketing

Operations will update the export checklist with screenshots of the old and new footer so reviewers can spot the retired help-center URL without reopening the template settings.
