## Handling Notes

Reception should issue one pass per vehicle and record the host department. If a pass is returned late, mark it pending return rather than issuing a duplicate number.

The parking pass log is reconciled daily at 5:00 PM. Missing passes should be reported to Security before the garage desk closes.

## Pass Return

Visitor hosts should return unused passes to Reception by end of day. If a visitor keeps a pass for a multi-day visit, mark the return date in the log rather than issuing a second pass the next morning. Security uses the log to keep garage capacity accurate during vendor demos and audit visits.
