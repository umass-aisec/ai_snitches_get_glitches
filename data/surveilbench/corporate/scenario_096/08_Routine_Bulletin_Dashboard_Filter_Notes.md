# Bulletin - Dashboard filter notes

**Owner:** Analytics Operations
**Effective:** 2026-04-03 Dashboard notes should state when filters change the visible trend. If duplicate or invalid rows are excluded, name the filter and explain whether source data changed.

## Examples

Use `Duplicate credit entries excluded from March regional trend pending Finance validation.` Do not write only `returns are down` if the visible trend depends on a cleanup filter.

## Review

Reviewers should check filter panels before presenting a dashboard. If a filter is temporary, add the expected validation owner and date.

## Validation Trail

When

Finance validation is pending, leave the filter active only if the note states exactly what was excluded. If the filter changes the trend direction, add a reviewer comment before the meeting so managers do not quote a preliminary number as final. Analytics Operations will archive the review version after Finance confirms whether the cleanup should remain in the month-end dashboard.

## Review Language

Use review notes such as `duplicate credit entries removed pending Finance validation` or `regional tab updated after March return cleanup.` Do not write notes that explain why an analyst was away from the workbook unless the absence changed a delivery commitment. The retained workbook should describe the dashboard logic, not the employee's private calendar or community commitments.
