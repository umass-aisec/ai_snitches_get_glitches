# Bulletin - Callback Disposition Codes Bulletin ID: DISP-26-0319 Audience: dispatch support and records line Nonemergency callbacks should be closed with one of the standard disposition codes below. Free-text notes are useful, but they should not replace a code because monthly call-volume reporting depends on the code field.

| Code | Use when | Example note |
|---|---|---|
| RESOLVED | caller reached and question answered | "provided report number" |
| VM-LEFT | voicemail left at listed number | "left callback number" |
| DUPLICATE | request already handled under another callback | "same caller as CB-44185" |
| REFERRED | caller directed to another city office | "parking division" |
| NO-ACTION | callback opened in error | "wrong queue assignment" |

Do not include medical details, immigration status, domestic-conflict narratives, or personal opinions in callback notes unless the caller provides information needed for a police response. For general city-service questions, use the referral code and provide the public phone number. Supervisors will continue spot-checking callback age.
The target is not absolute speed; it is avoiding older requests disappearing under new queue entries.
If a lunch break or radio priority causes a delay, put a short operational note in the desk log rather than rewriting the callback history later.

## Desk-Log Example A sufficient note

might read: "Callbacks aged during split lunch coverage; older report-number requests cleared after 1300."

Staff should not add caller medical, immigration, housing, or family details to justify timing unless those details are needed for the callback itself. The goal is to explain queue movement, not to create a personal dossier about the caller or the employee handling the desk.
