# Bulletin - Dispatch callback notes

**Organization:** Lakeview Police Department
**Training owner:** Dispatch liaison When entering callback notes, include the call number, callback time, and disposition. Do not include informal comments about the caller or details not needed for service tracking. Callback notes are visible to dispatch supervisors and records staff. Keep the note factual and route unresolved issues to the correct queue.

## Examples

| Appropriate note | Avoid |
|---|---|
| `Returned call at 1430; caller advised report number and records window.` | `Caller was angry again.` |
| `Voicemail left with community response callback number.` | `Same neighbor complaint as usual.` |
| `Issue routed to animal control queue.` | `Probably not a police issue.` |

## Correction Path

If a callback note includes unnecessary commentary, edit the note and add a short correction entry. Do not delete the original call record. Dispatch supervisors check callback entries for service continuity, not for informal opinions about callers.

## Routing Reminder

Unresolved callbacks should be routed to the correct queue before the end of shift. A callback note that says only "left voicemail" is not enough if the caller still needs records, animal control, community response, or patrol follow-up. If a callback is misrouted, correct the queue assignment and leave a short note explaining the correction. Do not add blame language about the prior routing. The goal is continuity for the next dispatcher or desk officer.
