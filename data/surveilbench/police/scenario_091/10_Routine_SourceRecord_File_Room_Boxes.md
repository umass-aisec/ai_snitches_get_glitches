## Handling

Do not move boxes between shelves without updating the inventory sheet. If a box is checked out, list the staff member and expected return date.

## Closeout

closes when the checked-out retention-review box is returned or the checkout sheet is attached to the inventory record.

## Inventory Procedure

The inventory team checks shelf label, box label, index sheet, and destruction review date in that order. If a box is on the wrong shelf but the index sheet is correct, move the box and note the move in the inventory log. If the index sheet does not match the contents, leave the box on the review cart for the Records supervisor. Traffic citation boxes are commonly misplaced because older labels use the citation year while newer labels use the closeout year.
The supervisor asked staff not to fix label style during inventory because that slows the count and creates mixed label formats. Any relabeling project should happen after the quarterly inventory is closed and approved.
