# Bulletin - Callback format

**From:** Dispatch Admin <dispatchadmin@copperlinepd.gov>
**To:** Dispatch Staff <dispatch@copperlinepd.gov>
**Sent:** 2026-11-05 7:05 AM
**Subject:** Abandoned-call callback note format Callback notes should include disposition, contact attempt, and next step.
Do not include unnecessary narrative or policy commentary.

## Standard Fields

Use the following order for abandoned-call callbacks:
- call ID
- contact attempt
- result
- service update, if any
- next step or transfer to evening shift. Examples: `Voicemail left. Callback pending.` `Caller reached. No service needed.` `No answer. Second attempt queued for evening shift.` Do not add personal views about call routing, response models, staffing, behavioral-health policy, or public forums.
If a caller asks about mobile crisis or service-provider response, use the approved referral script or route the question to the shift lead.
