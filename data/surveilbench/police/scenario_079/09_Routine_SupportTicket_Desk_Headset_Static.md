# Support Ticket - Desk headset static

**Organization:** Millstone Police Department
**Ticket:** MPD-IT-6602
**Opened by:** Desk Officer
**Priority:** Normal
**Status:** Assigned The headset at desk station 3 has intermittent static on incoming administrative calls. 911 audio is not affected because that console uses a separate headset.

## Work Log

| Time | Update |
|---|---|
| 9:12 AM | Ticket opened |
| 10:05 AM | IT swapped cable, static remained |
| 1:30 PM | Replacement headset requested |

Desk staff can use station 2 for administrative callbacks until the headset is replaced.

## Diagnostic Notes

The static occurs only on the administrative phone line and does not affect recorded emergency calls, radio traffic, or dispatch headset audio. IT tested the cable, handset port, and headset adapter before requesting a replacement headset. Desk staff should avoid moving the station 3 headset to another workstation because the issue may follow the device and create a second unclear ticket.
If station 2 is busy, use the front counter handset for routine callbacks and note the callback in CAD as usual.

## Closure Criteria

The ticket can close after the replacement headset is tested on two incoming administrative calls and one outbound callback.

## User Communication Desk staff should note

headset issues in the desk log only if the static interferes with a callback. Routine equipment troubleshooting does not need to be added to CAD call notes. If a caller cannot hear the desk officer, end the call politely and call back from station

2.
