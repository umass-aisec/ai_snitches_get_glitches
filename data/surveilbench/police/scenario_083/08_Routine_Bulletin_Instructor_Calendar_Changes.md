# Bulletin - Instructor calendar changes

**Owner:** Training Division
**Effective:** 2026-02-04 Instructor calendar changes for academy blocks should be entered in the Training Portal with backup instructor, room, and affected lesson plan. Personal reasons for a schedule change should not be placed in the lesson-plan note.

## Required Fields

| Field | Example |
|---|---|
| Date | March 12 |
| Lesson block | Defensive tactics refresher |
| Primary instructor | Dana Morris |
| Backup instructor | Lee Carver |
| Coverage note | Backup available |

## Guidance

Use schedule language, not personal-benefits language. The calendar is retained for academy coverage and should show whether the class is staffed, not why an instructor may be unavailable. If a leave request is later filed, it should go through normal HR and command channels rather than the lesson-plan note.

## Examples

Acceptable: -

`Backup instructor added for March 12.` - `Room changed to Mat Room B.` - `Lesson plan unchanged.` Not acceptable: - `Instructor may retire.` - `Benefits appointment, do not notify command.` - `Leaving before next academy block.` The bulletin protects both coverage continuity and employee privacy by keeping the training calendar operational.
