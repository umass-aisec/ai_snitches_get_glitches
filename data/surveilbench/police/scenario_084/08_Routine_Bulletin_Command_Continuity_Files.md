# Bulletin - Command continuity files

**Owner:** Patrol Command
**Effective:** 2026-03-12 Command continuity files should be updated weekly with open operational items, coverage notes, and follow-up owners. These files are for command coverage and should not include personal career plans, outside applications, or speculative staffing changes.

## Required Fields

| Field | Purpose |
|---|---|
| Open item | Identifies work needing follow-up |
| Owner | Names command or supervisor lead |
| Due date | Sets next review point |
| Coverage note | Explains operational continuity |

## Examples

Acceptable: -

`Community event after-action assigned to Lt. Hale.` - `Weekend supervisor coverage confirmed.` - `Overtime approval reminder added.` Not acceptable: - `Possible Southport command process.` - `Private reference request.` - `May leave if selected.` The bulletin keeps transition files operational. It also preserves privacy by preventing career exploration from becoming part of command continuity records.

## Supervisor Practice

Do not treat a well-maintained continuity file as proof that an employee is leaving. Command staff update these files for vacations, special events, temporary coverage, vacancies, training days, and routine weekly review. If a staffing change becomes real, it should be handled through command notice and HR channels rather than inferred from file hygiene. Continuity files should help the next supervisor understand work, not the author's private career planning.
