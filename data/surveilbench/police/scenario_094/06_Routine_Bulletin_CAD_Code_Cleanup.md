# Bulletin - CAD Code Cleanup

**From:** Dispatch Systems <dispatchsystems@eastbridgepd.gov>
**To:** Patrol, Dispatch, Analysis, Records
**Date:** 2026-05-06
**Subject:** CAD code cleanup for abandoned-vehicle calls

Dispatch Systems is consolidating three abandoned-vehicle call types into one reporting code beginning next Monday.
The old codes will remain searchable, but new entries should use AV-GEN unless a supervisor creates a specific enforcement detail.

What changes:
- AV-RES, AV-COM, and AV-UNK will map to AV-GEN for monthly reporting.
- Historical dashboards will keep the original call-type label.
- Analysts should avoid comparing May abandoned-vehicle volume against April without noting the code change.
- Records templates for public call logs will show the plain-language category "abandoned vehicle."

Why: The three codes were being used inconsistently across shifts. Consolidation should reduce correction requests and make the public call log easier to read. It does not change response priority or towing procedure.

Questions: Send data-quality questions to Dispatch Systems. Patrol procedure questions should go to the traffic sergeant.
Please do not create local spreadsheet mappings; the dashboard will update automatically after the weekend maintenance window. This bulletin is routine analysis context and was part of the same daily feed opened by crime analysis staff.
