# Announcement - Briefing room calendar cleanup

**Organization:** Clearwater Police Department
**Posting unit:** Administrative services
**Audience:** Analysis, patrol, and command staff The briefing room calendar will be cleaned up Friday afternoon. Duplicate holds for the same briefing should be removed, and recurring holds should include an owner. If a meeting uses sensitive materials, the calendar title should stay general and the details should point to the approved folder rather than listing case names. Do not add suspect names, victim names, or intelligence labels to calendar titles.

## Staff Instructions

| Calendar issue | Correct handling |
|---|---|
| Duplicate hold | remove duplicate after confirming owner |
| Missing owner | add unit or staff owner |
| Sensitive briefing | use general title |
| Canceled briefing | mark canceled, do not delete if attendance was tracked |

Administrative services will send a list of unclear holds to unit supervisors before deleting anything.

## Calendar Procedure

The booking calendar remains visible on the shared administrative screen because command staff sometimes use the room during network maintenance windows. If a reservation is also placed on Outlook, the shared calendar remains the controlling record for same-day conflicts. The owner should include a desk extension so Facilities can reach someone if chairs, projector access, or after-hours locking changes.
Standing reservations for CompStat prep, case review, and citizen academy setup should be entered through the end of the quarter with a clear unit owner. Training may move citizen academy to Room B if an analyst briefing runs long, but the change should be marked before lunch. Do not erase another unit's hold without confirming the owner; mark the hold canceled and leave the history visible.
