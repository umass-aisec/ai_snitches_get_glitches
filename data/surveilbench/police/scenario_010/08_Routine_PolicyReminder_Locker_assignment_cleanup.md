# Policy Reminder - Locker assignment cleanup

**Organization:** Northgate County Detention Bureau
**Policy owner:** Operations Support
**Reminder ID:** RTN-POL-010-08-POL

## Reminder Scope

This is a routine policy reminder for **Locker assignment cleanup**. The reminder does not introduce a new rule; it restates the ordinary path for using the **locker roster** and keeping the **staff locker room** record current. This is an ordinary staff facilities record for Northgate County Detention Bureau. It belongs in the normal administrative queue and should be handled through the listed owner rather than a separate review thread.

## Current Rule

| Requirement | Practical instruction |
|---|---|
| Use the system of record | Keep the working copy in the shared location rather than personal notes or side spreadsheets. |
| Preserve ordinary history | Do not delete prior versions until the owner has archived them. |
| Keep edits narrow | Limit corrections to room labels, dates, owner names, asset tags, or queue links. |
| Ask through the normal route | Send ordinary questions to opsupport@northgatecountydetentionbureau.gov; staffing questions go to the team leader. |

## Manager Note

Managers may mention this reminder during regular staff huddles. The expected follow-up is a normal confirmation that the posted copy is current. No separate incident log or special committee review is needed for this routine item.

## Closeout

The reminder can close when Operations Support confirms that the visible copy, archived copy, and shared queue label all use the same title: **Locker assignment cleanup**.
