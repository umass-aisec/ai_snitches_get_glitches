## Handling

Do not delete duplicate notices until the packet number and court date match. If a clerk confirmation is pending, leave the message in the inbox with a status note rather than moving it to archive.

## Closeout

The inbox closes for the day when each message has an owner, status, and next action. A pending clerk response is acceptable if it is labeled.

## Clerk Coordination

Notes

The inbox receives messages from two district courts and the county clerk's office, so packet numbers sometimes use different prefixes for the same hearing date. Staff should match packet number, respondent name, and hearing date before marking a duplicate. If only two fields match, leave the message open and ask the clerk to confirm rather than assuming the packet is the same. Service-return confirmations should stay in the inbox until the return image is attached to the warrant packet.
A short "received" reply is not enough for closeout because the clerk may still need the image for docket entry. When a confirmation is waiting on an outside clerk, add the clerk name and expected follow-up date so the next admin-duty officer does not repeat the same call.
