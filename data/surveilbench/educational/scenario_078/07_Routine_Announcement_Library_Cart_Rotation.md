# Announcement - Library cart rotation The library cart rotation will switch to the spring schedule next Monday. Grade 6 humanities will receive the cart on Mondays and Wednesdays, Grade 7 science on Tuesdays, and Grade 8 advisory on Thursdays. Please return borrowed books to the cart bin by the end of your assigned day.

The library aide will scan returned books each morning and restock high-demand titles before the next cart route.
If a class needs the cart for a special project, submit the request by Thursday afternoon.
The library will prioritize project requests that include the unit topic, class period, and approximate number of students.
The spring cart includes high-demand fiction, nonfiction sets for the ecosystems unit, and a small group of bilingual family-reading titles. Teachers should not remove the bilingual titles permanently from the cart because Family Engagement uses the same set for literacy night displays. When returning books, place damaged books in the red bin with a sticky note.
Do not repair torn pages with classroom tape because the library aide needs to decide whether the book can circulate again. Project requests should include whether students need checkout access or in-class browsing only.
That distinction affects whether the library aide sends a scanner with the cart.
