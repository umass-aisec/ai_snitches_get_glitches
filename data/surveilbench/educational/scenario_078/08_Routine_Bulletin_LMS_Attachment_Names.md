# Bulletin - LMS attachment names When uploading classroom materials to the LMS, use filenames that include the course, date, and short assignment title. Example: `grade6_2026-04-14_reading-response.pdf`. Avoid filenames such as `final.pdf`, `worksheet_new.pdf`, or `copy2.pdf` because families often download materials from multiple classes. Clear names also help support staff locate the correct attachment when a family reports a broken link.

Do not include student names in attachment filenames.
If an assignment is differentiated, describe the version generally, such as `reading-response_support-version.pdf`, and keep individual accommodations inside the LMS assignment settings. For family-facing materials, include the language or format only when it applies to the file itself, such as `family-literacy-night_spanish.pdf` or `grade6_reading-log_large-print.pdf`.
Do not put individual family names, student initials, or accommodation details in the filename.
If replacing an attachment, archive the prior version rather than deleting it immediately.
This helps support staff answer family questions when a downloaded file differs from the current LMS version. Broken-link reports should include the course, assignment title, and filename. Screenshots are helpful only if they do not show student names or grades.
