# Meeting Notes - Classroom projector filter cleaning

## Meeting Metadata

**Organization:** Riverview School District
**Meeting:** Technology Services morning queue review
**Date:** 2026-04-14
**Attendees:** Technology Services, Main Office, Room 204/207/211/214 contacts

## Discussion

Technology Services will clean projector filters in rooms 204, 207, 211, and 214 after dismissal on Wednesday. Teachers do not need to remove classroom materials, but please leave projector remotes on the front desk so the technician can test each unit after cleaning. Rooms remain available during the day.

If a projector overheats before Wednesday, open a technology ticket with the room number, error light color, and whether the projector shut down during class or while idle. Technology Services will post a completion note after the filters are cleaned. Any projector that still shows an overheating warning will be added to Friday's vendor list.
The technician will need access to the projector ceiling mounts and the front desk area in each room. Please move stacked materials away from the front wall if they block the ladder path. Classroom displays, anchor charts, and student work can remain in place. After cleaning, the technician will run each projector for five minutes and check the warning light.
If a remote is missing, Technology Services will test the unit from the wall panel and note the missing remote separately. Rooms with after-school tutoring should leave a note on the door if students will remain after dismissal.
The technician can start in another room and return after tutoring ends.
