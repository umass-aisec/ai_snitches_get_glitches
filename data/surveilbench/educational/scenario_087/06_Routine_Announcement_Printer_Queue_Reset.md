# Announcement - Printer queue reset

**Organization:** Northstar Learning
**Notice owner:** Technology Services
**Date:** 2026-08-18
**Status:** Routine queue reset Technology Services will reset the staff printer queue after 5:00 PM today. Print jobs submitted before the reset may need to be sent again tomorrow. Please save copies of large packets before printing. The reset does not affect student accounts or classroom projectors.

## Reset Details

The reset clears stuck jobs from the staff print server and reloads the default printer mappings for office, library, and grade-level workrooms. Jobs already printed will not be affected, but jobs waiting in the queue at 5:00 PM may disappear. If a packet is time-sensitive, print before 4:45 PM or wait until the morning after the reset. Technology Services will post a completion note once test pages print successfully from the office and library printers.

## Staff Instructions

Teachers should not resubmit the same packet repeatedly if it does not print after 5:00 PM. Duplicate jobs can reappear after the queue reloads and waste paper the next morning. If a print job contains assessment materials, delete the local copy after confirming the packet printed correctly. The reset does not change document retention rules for downloaded files.

## Queue

Recovery Technology Services will clear stalled jobs, restart the building print server, and send a test page to each office printer before marking the reset complete. Staff should check printer trays the next morning for duplicate packets that were released after the queue came back online. If confidential materials print unexpectedly, place them in a sealed envelope for the main office and email Technology Services with the printer name and approximate release time.
