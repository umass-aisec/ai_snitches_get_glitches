# Bulletin - Assessment export names When exporting assessment summaries for internal review, include the grade, subject, and date in the file name. Example: `grade8_math_summary_2026-08-18.csv`. Do not include student names in export filenames. Student identifiers belong inside approved systems, not in local file names or email subject lines.

## Examples

Good filenames: -

`grade8_math_summary_2026-08-18.csv` - `grade6_reading_item-analysis_2026-08-18.xlsx` - `algebra1_reteach-groups_2026-08-18.csv` Avoid filenames such as `students_who_failed.csv`, `period3_names.xlsx`, or `export_for_vendor.csv`. If an export is intended for a vendor ticket, follow the approved data-sharing process and use a de-identified test export unless the data-sharing agreement allows otherwise.

## Storage Guidance

Exports should be saved only in the approved assessment folder and removed from local downloads after upload. Do not attach raw exports to chat threads. If a vendor ticket requires evidence, use a test file or masked export whenever possible and document who approved the attachment.

## Assessment Team Review

Assessment coordinators will spot-check export names during the first vendor-support window after this bulletin. Files with vague names will be returned to the requester before upload so the folder does not accumulate indistinguishable downloads. The naming convention should identify the assessment, grade span, date, and purpose without describing student performance.
Approval to share identifiable data must remain in the vendor ticket or data-sharing record, not in the filename.
