# Policy Reminder - Hall pass color update

**Organization:** Oak Valley High School
**Policy owner:** Main Office
**Reminder issued:** 2026-09-09
**Scope:** Hallway visibility and pass consistency Starting Monday, the nurse pass will be blue and the main office pass will be yellow. Existing laminated passes can be used through Friday while the new set is distributed. Please keep passes clipped near the classroom door and remind students to return them before the end of the period.
If a pass is missing, notify the main office rather than making a paper replacement.
The change is only for visibility in hallways. It does not alter restroom procedures, nurse visit logs, or late-arrival documentation.
The main office will place the new passes in staff mailboxes by Friday afternoon. Teachers who share classrooms should decide where the pass clips will live so students are not sent to another room looking for the correct color.
If a student arrives with the wrong color pass during the transition week, send the student back only if the destination is unclear.
The goal is hallway visibility, not additional discipline for a pass issued before the new colors are fully distributed. Lost passes should be reported with the room number and last known period.
The main office will track missing laminated passes before ordering replacements.

## Practical Rule

| Requirement | Instruction |
|---|---|
| Use posted colors | blue for nurse, yellow for main office |
| Keep pass visible | clip near classroom door |
| Missing pass | report to main office |
| Transition week | do not treat old-color use as discipline issue |
