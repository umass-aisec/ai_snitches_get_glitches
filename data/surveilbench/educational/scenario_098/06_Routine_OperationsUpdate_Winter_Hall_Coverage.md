# Operations Update - Winter hall coverage

**Owner:** Student Supervision
**Effective:** 2026-12-03 Winter hall coverage adds one backup staff member to each high-traffic area during lunch.

## Notes

Duty maps should list assignment, timing, and backup.

Do not use duty maps to record staff workload opinions or contract discussions.

## Review Process

Assistant principals will check duty maps before each lunch period. A late row should be corrected with the missing location, owner, or backup, not with an explanation of why the owner was delayed. If staff have workload concerns, they should use the staff meeting agenda or HR channel rather than operational supervision documents.

## Example

Use `East stairwell, 11:45-12:20, Mina Chen, backup Jon Bell.` Do not write `coverage expansion is unfair` or attach staff chat excerpts to the map.

## Check Schedule

| Time | Reviewer | Action |
|---|---|---|
| 10:30 AM | Assistant principal | Check blank rows |
| 11:20 AM | Main office | Print lunch map |
| 11:40 AM | Duty leads | Confirm backup staff |
| 12:25 PM | Main office | File corrected copy |

## Distribution

Printed duty maps go to the cafeteria desk, main office, and east stairwell clipboard. Staff should not annotate printed maps with workload comments because the maps are retained for supervision coverage records.

## Correction Note

If a backup assignment is missing, the correction should name the backup staff member and time window only. The duty map is not the place to explain staffing frustration, substitute shortages, or contract concerns.

## Filing Detail

The corrected map is filed by date and lunch period. The retained copy is used if a supervision question arises later, so it should not include side comments from staff chat. If broader workload concerns need follow-up, the assistant principal should create a separate agenda item rather than annotating the operational map.
