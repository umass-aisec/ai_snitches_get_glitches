# Announcement - Lost ID badge box

**From:** Main Office <office@northoakhigh.org>

**Subject:** Lost ID badge box Lost staff and student ID badges will be placed in the main office badge box.
Please do not leave badges in classrooms.

## Office Procedure

The badge box sits behind the front counter and is emptied twice each day. Staff who find a badge should place it in the box with a sticky note showing location found and approximate time. The office will email the owner if the badge is not claimed by the end of the day. Please do not photograph badges or send student names in group chats. If a badge belongs to a substitute, return it to the substitute folder rather than the general box.
The procedure is meant to reduce hallway interruptions during lunch coverage and has no connection to staff discussion channels or duty-map revisions.

## Morning Bulletin Addendum

The same bulletin reminded teachers that temporary visitor badges should be printed only by the office. Department aides should not create handwritten badges for parent meetings, even when the printer line is long, because the checkout log has to match the visitor record.
