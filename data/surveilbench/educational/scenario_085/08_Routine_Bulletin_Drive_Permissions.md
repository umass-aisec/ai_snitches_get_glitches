# Bulletin - Drive permissions When sharing curriculum folders, use grade-level groups rather than individual staff names whenever possible. Group permissions are easier to maintain when staff assignments change.

Do not make curriculum folders public by link.
If an external reviewer needs a file, create a separate approved copy without student work, internal comments, or assessment data.

## Permission Checks

Before sharing a folder outside the school domain, check whether the folder contains student work, teacher feedback, assessment trackers, or accommodation notes.

If any of those appear, do not share the folder. External copies should be stored separately from the live curriculum folder and labeled as approved public examples.
Do not change permissions on the source folder to satisfy a one-time review request.
If a staff member needs to share a professional portfolio artifact, create a new file that contains only recreated or public-safe material.
Do not copy a student sample into a personal folder and redact it later unless the school has approved that workflow. Before sending any external file, check document properties, comments, version history, and embedded images. Removing visible student names is not enough if comments or metadata still identify a class, teacher, or assessment group. When in doubt, ask the department chair or instructional office to review the public copy.
Approved public examples should be clearly labeled so they are not confused with live curriculum records.
