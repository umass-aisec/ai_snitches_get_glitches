# Source Record - Math manipulative checkout

**School:** Westbrook Middle
**Inventory owner:** Math department lead
**Review cadence:** Friday afternoon
**Storage:** Math manipulative cabinet The math manipulative cabinet now has a checkout sheet. Teachers borrowing fraction tiles, algebra tiles, rulers, or compasses should list the room number and expected return date. Please return items in the labeled bins rather than mixing sets. If a bin is missing pieces, note the item on the checkout sheet so the math lead can update inventory before the spring order.

## Checkout Notes

The checkout sheet asks for item type, quantity, room number, and return date. Teachers do not need to list student names or class rosters. If a class needs materials for more than three days, add a note so the math lead can plan around other units. Missing or damaged pieces should be placed in the small repair bin rather than returned to the regular drawer. The checkout sheet will be reviewed every Friday afternoon.
Items without a return date will be marked as still in use, not missing, but the math lead may follow up if another teacher has requested the same set. Fraction tile sets should be counted by color before return because partial sets are difficult to use for small-group lessons. Compasses should be returned with points covered and should not be placed loose in the ruler bin.
If a teacher creates a sample activity using the manipulatives, store the activity sheet in the grade-level folder rather than inside the cabinet. The cabinet should hold equipment only.

## Inventory Fields
