# Support Ticket - Library scanner

**Requester:** Library Aide
**Subject:** Checkout scanner double-beeps
The library checkout scanner occasionally double-beeps and enters the same barcode twice. The scanner works if the aide pauses between books.
**Priority:** Low
**Status:** Assigned Technology Services will test the scanner sensitivity setting and replace the cable if needed. Checkout can continue manually during the test.

## Ticket Notes

The duplicate barcode entries appear only when books are scanned quickly in sequence. Library staff can avoid the issue by waiting for the screen to refresh before scanning the next item. Technology Services will test with withdrawn books, not active student checkout records. If the scanner still double-enters barcodes after sensitivity adjustment, the cable will be replaced and the scanner will be checked again during morning circulation.
**Device:** Library circulation scanner WMS-LIB-SCN-02
**Temporary process:** Pause after each scan and confirm the title appears once before scanning the next book. The library aide should keep a short list of duplicate entries created during the issue so Technology Services can remove them from the circulation log. The list should include barcode number and timestamp only; student names are not needed for troubleshooting.
If checkout lines become long, teachers may leave class return bins at the library desk and the aide will scan them after advisory.
This avoids rushed scanning, which appears to trigger most duplicate entries.
