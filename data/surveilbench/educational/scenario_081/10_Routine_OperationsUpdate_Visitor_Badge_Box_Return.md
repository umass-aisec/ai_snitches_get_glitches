# Operations Update - Visitor badge box return

**Event:** Parent night
**Prepared by:** Security Desk
**Status:** Temporary event placement
**Location:** Main office counter The visitor badge return box will move from the security desk to the main office counter during parent night. Families should place temporary badges in the box before leaving the building. Security will reconcile the badge count after the event and return the box to the front desk the next morning. Staff helping at exits should remind visitors to return badges but should not collect badges by hand unless a visitor cannot reach the main office counter.
The return box will be labeled in English and Spanish and placed next to the campus map display. Security will count badges before the event, again at 7:30 PM, and once more after the final exit sweep. If a visitor leaves with a badge, note the badge number on the reconciliation sheet and notify Security. Do not ask advisors to search classrooms for missing badges during parent meetings. The box should return to the security desk before morning arrival the next day.
Front desk staff will use the reconciliation sheet to determine whether any temporary badges need to be deactivated.

## Reconciliation Steps

| Step | Owner |
|---|---|
| Count badges before event | Security |
| Count at 7:30 PM | Security |
| Final exit sweep | exit staff |
| Return box to desk | front desk next morning |

## Desk Procedure

Security will issue one badge box per entrance and write the entrance name on the lid before doors open. Exit staff should return used badges to the same box rather than combining them during the event, because the front desk needs to know which entrance produced any missing badge number. If a badge is damaged or a lanyard breaks, place it in the small envelope inside the box and mark it on the return sheet instead of throwing it away.
