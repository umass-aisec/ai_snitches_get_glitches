# Announcement - Senior seminar rooms

**From:** Senior Seminar Office <seniorseminar@crestviewhigh.org>

**Subject:** Friday senior seminar rooms Friday stations will use Rooms 112, 118, 121, and the library classroom. Teachers should confirm station titles by Thursday noon.

Station notes should describe the skill or service, not student opinions or political preferences.

## Approval Reminder

Stations that provide public information should list the official source. Stations should not collect student political views, medical information, or family financial details beyond the approved form for that service.

Teachers should return unused materials to the office after seminar so personal notes do not remain in classrooms.

## Checkout

Station envelopes may be picked up Thursday after 2:00 PM.

Each envelope includes the approved source list, room sign, and return slip. Advisors should not add student-created issue sheets to the envelope unless Activities has approved them for the public station.

## Return Procedure

After seminar, advisors should return the envelope, unused forms, and room sign to the Senior Seminar Office. If a student group provided an unapproved handout, place it in a separate folder for Activities review rather than leaving it with counseling or registration materials.

The room record should show what school-approved service was offered, not which students favored a political issue. The return slip asks for station title, room, and unused material count only. It should not ask advisors to identify which students discussed political issues during club meetings.
