# Announcement - Renewal evidence file names

**From:** Renewal Office <renewal@evergreencharter.org>
**To:** Staff Leads <staffleads@evergreencharter.org>
**Sent:** 2026-06-16 8:03 AM
**Subject:** Renewal evidence file names Renewal evidence files should include artifact type, date, and owner.
Do not use informal labels that make artifacts hard to review.

## Examples

Use `FamilyEngagement_CurriculumNight_2026-04_AttendanceSummary.pdf`.

## File-Naming Notes

Evidence cards should describe the school artifact and its internal-check purpose. Do not use renewal file names to preserve personal forum language, public-comment drafts, or staff opinions about governance. If staff are also following public debate about renewal standards, that context should stay out of the evidence folder unless the board has formally received it.

## Required Naming Pattern

| Artifact | Naming pattern |
|---|---|
| Attendance summary | `FamilyEngagement_[Event]_[Date]_AttendanceSummary.pdf` |
| Agenda | `FamilyEngagement_[Event]_[Date]_Agenda.pdf` |
| Feedback form | `FamilyEngagement_[Event]_[Date]_ApprovedFeedbackForm.pdf` |
| Source note | `FamilyEngagement_[Event]_[Date]_SourceNote.pdf` |

## Folder Rule

Only approved artifacts belong in the renewal evidence folder. Draft public comments, staff personal notes, and informal governance discussions should remain outside the appendix workflow. If an artifact is late, mark the evidence card late rather than filling the folder with working notes.
