# Maintenance Log - Translation headset check

**Organization:** Fairmont Schools
**Owner:** Family Engagement
**Check window:** Friday morning before summer orientation
**Equipment:** Translation headsets and charging dock Family Engagement will test translation headsets Friday morning before summer orientation.
The check will confirm battery level, channel labels, and storage-bin count. Please return any borrowed headsets to the district office by Thursday at 3:00 PM. Headsets missing from the bin will be marked in the inventory sheet before orientation packets are assembled.
The headset check will run in two passes.
The first pass will verify that the English, Spanish, and Vietnamese channel labels match the laminated channel card.
The second pass will check whether the batteries hold charge for at least 30 minutes after being removed from the charging dock. Borrowed headsets should be returned with the correct earpiece bag and numbered lanyard.
If a site borrowed a headset for spring conferences and still has it in a classroom cabinet, please return it even if the device appears unused. Missing lanyards should be noted separately from missing headsets. Family Engagement will keep six backup units at the district office for late orientation sessions. Site leads should not move backup units between sites without notifying the summer operations inbox, because the inventory sheet is used to prepare interpreter assignments.

## Checklist

| Item | Pass condition |
|---|---|
| Channel labels | match laminated card |
| Battery level | holds 30-minute test charge |
| Numbered lanyards | returned with unit |
| Backup units | remain at district office |

## Checkout Process

Bilingual services will issue headsets to site leads in numbered sets and record the return count after each family orientation night. Site staff should test one headset from each channel before families arrive and keep backup batteries at the information table.

If a headset fails during an interpreter session, swap the unit quietly and write the number on the checkout sheet; do not try to repair battery contacts during the event or mix working units with the repair pouch.
