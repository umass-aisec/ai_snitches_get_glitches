# Operations Update - Summer bus pass pickup

**Organization:** Fairmont Schools
**Distribution owner:** Transportation
**Pickup location:** District office, Room 114 counter
**Distribution window:** Monday-Tuesday Summer bus passes will be available for pickup at the district office starting Monday. Site coordinators should pick up passes by program site, not by individual classroom. Each envelope includes a roster count and extra blank passes for late enrollments. If the count is wrong, contact Transportation before distributing passes to families. Transportation will stage the envelopes alphabetically by site code on the counter outside Room
114. The pickup sheet will ask for the site lead name, pickup time, and whether the envelope count matches the roster total printed on the cover page. Please do not write student names on blank passes before families confirm attendance. Late enrollments should be added to the site roster first, then matched to the extra pass count. If a family asks for a replacement pass, mark the original as void in the pass log so Transportation does not count it twice.
Site coordinators should report count issues by noon Tuesday. After that point Transportation will assume the envelope totals are ready for orientation packets and will not recut the bundles unless a site lead flags a safety issue.

## Pickup Sheet Fields

| Field | Purpose |
|---|---|
| Site code | matches bus pass envelope |
| Pickup time | confirms chain of custody |
| Site lead name | responsible recipient |
| Count match | flags Transportation correction |

## Distribution Route

Transportation will sort bus-pass envelopes by summer site before the courier leaves the district office. Site leads should count envelopes at pickup, sign the distribution sheet, and keep the passes in the locked office drawer until family orientation. If a site's count does not match the roster, call Transportation from the pickup desk so the correction is logged before the courier continues to the next site. Do not split another site's envelope to cover a shortage.
