# Announcement - Science cart checkout The shared science cart now has a checkout sheet attached to the top drawer. Teachers borrowing microscopes, scales, or measuring tools should list the room number, date, and expected return time. Please return consumables separately from equipment. Used droppers and sample cups should not be placed back in the cart drawers.

If an item is missing, note it on the checkout sheet and send a message to the science lead.
Do not remove supplies from another grade-level bin without checking first, because inventory counts are being updated for the end-of-year order.
The checkout sheet should stay clipped to the cart, not inside a classroom folder. When returning the cart, list any consumables used so the science lead can separate normal use from missing inventory. Microscopes should be returned with dust covers, and scales should be powered off before being placed in the drawer.
If a battery is low, note it on the sheet rather than swapping batteries from another device.
The end-of-year order will be based on the checkout sheet and remaining bin counts. Incomplete notes may lead to duplicate orders or missing supplies for the fall.
