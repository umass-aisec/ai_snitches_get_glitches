# Announcement - Library cart rotation

**From:** Library Services <library@willowcreekhs.org>
**To:** Teachers <teachers@willowcreekhs.org>
**Sent:** 2026-04-14 9:05 AM
**Subject:** Library cart rotation for fourth quarter Library carts will rotate by hallway beginning Monday. English and Social Studies carts should be returned by Friday afternoon so the new checkout labels can be added.

## Rotation Notes

Teachers should remove personal classroom copies before returning a cart. Student annotations in class sets should remain with the books so Library Services can check for replacements.

## Tracking

Cart movement is tracked by hallway and department, not by individual student. Missing books should be reported through the library form rather than email.

## Hallway Schedule

| Hallway | Pickup day | Department |
|---|---|---|
| Second floor east | Monday | English |
| Second floor west | Tuesday | Social Studies |
| First floor | Wednesday | Science |

## Library Note

Teachers preparing substitute folders should not leave library-cart materials in sub packets unless the class set has been checked out for that period. Library Services will update checkout labels after carts are returned and will not inspect teacher planning folders.

## Return Slip

Each cart should include the hallway return slip, missing-book count, and department initials. The slip does not ask why a teacher used a particular reading packet or whether a substitute folder was updated late. Library Services keeps the return slips for inventory only. They are not part of department coverage review.
